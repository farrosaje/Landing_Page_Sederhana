<h1 align="center">📖 DESKRIPSI PROYEK</h1>

Proyek ini merupakan landing page bisnis modern berbasis HTML, CSS, dan JavaScript yang menampilkan desain elegan dengan efek visual interaktif dan performa optimal.

# Landing page bekerja dengan cara:

-Menampilkan animasi gradien nebula sebagai background

-Menghasilkan partikel bergerak dengan Canvas API

-Memberikan efek interaksi saat scroll dan hover

=Menggunakan layout responsif untuk semua perangkat

-Sistem ini dilengkapi dengan fitur:

-Hero section dengan animasi dinamis

-Features grid yang responsif

-Navigasi fixed dengan efek blur

-Animasi hover pada semua elemen interaktif
